# M9.17 chain-walk route 1: the map the first level change out of
# ohl_campaign::STARTMAP ("c0a0") lands in, walked from the *arrival*
# point rather than from that map's own info_player_start.
#
# Project-authored; no bytes here come from any game installation (see
# docs/CLEAN_ROOM.md). The destination map's own name is deliberately not
# written down anywhere in this repository: it is a fact about the user's
# payload, not a lawfully public one, so this file is named by its position
# in the chain instead (see xtask/src/chain_walk.rs's module documentation
# and docs/CLEAN_ROOM.md rule 7).
#
# A line's leading number is a count of *ticks*, each one CAPTURE_STEP
# (1/60 s) of simulated time — not seconds.
#
# Route, in words only (no entity name, path or coordinate from any
# payload): the transition carries the player in still riding the start
# map's opening mover, which keeps going on this map's own copy of the
# same track (that carry is what M9.17 fixed; before it, the mover in this
# map drove off without its passenger and the campaign stopped here). The
# two short steps at the top move the player off the wall of the car they
# arrived pressed against and toward the middle of it, which is what keeps
# them aboard through the corners: a rider is carried by a mover's
# translation only, so a passenger standing at the edge of a turning car
# keeps their *world* offset from it and is eventually scraped off against
# the tunnel — see docs/MILESTONES.md M9.17 for that open gap. The long
# wait is the ride itself. Where the ride finally does put the player
# down, the walk lines cover the last stretch to the level change on foot.
#
# The trailing wait is slack: `run_chained` (crates/ohl-app/src/game_run.rs)
# ends a route at the level change it reaches, so any ticks left over here
# are never run.
