# Route, in words only (no entity name, path or coordinate from any

# matching the technique documented in
# xtask/smoke-scenarios/reach_level_change_anomalous_materials.txt. Runs
# whose per-tick turn is not bit-for-bit identical to its neighbor are
# kept as their own single-tick line rather than merged, which is why
# many lines below carry small fractional-degree turns. The run is
# deterministic, so replaying these inputs reproduces the same route
# every time.
