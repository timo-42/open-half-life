# M9 scripted-input scenario: a spawn-to-exit progression walk in
# "We've Got Hostiles!"
#
# Project-authored; no bytes here come from any game installation (see
# docs/CLEAN_ROOM.md). Run against "c1a3" ("We've Got Hostiles!", per
# ohl_campaign::CHAPTERS's own cited table) by xtask/src/combat_smoke.rs,
# with `--follow-level-change` so a `trigger_changelevel` this walk
# reaches is actually followed rather than only logged as "not followed".
#
# Route, in words only (no entity name, path or coordinate from any
# payload): from the player's spawn point, advance forward through a
# series of turns, opening a door along the way with a `use` press once
# it is within reach, then continue forward through a further sequence of
# turns and waits until a level change fires; then wait out the
# transition.
#
# Technique: an autopilot was flown over this map's own collision hulls,
# pressing `use` whenever a usable brush entity came within
# ohl_engine::USE_RADIUS, and the per-tick inputs it applied were
# recorded and merged into the whole/fractional-degree turns below,
# matching the technique documented in
# xtask/smoke-scenarios/reach_level_change_anomalous_materials.txt. The
# run is deterministic, so replaying these inputs reproduces the same
# route every time.
#

# from this file:
#   present: "Scripted input loaded.", "Scripted input finished.",
#            "The player moved from the spawn point.",
#            "The player opened a door.",
#            "A level change was followed."
#   absent:  "The player is inside solid geometry." (this scenario's own
#            regression guard for the PR #91 class of bug)
